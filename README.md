# 🧘 ZenSpace // Осознанность, Дыхание и Студийный Звук

> Минималистичное веб-пространство для медитации, дыхания и глубокого релакса со студийными русскими голосовыми практиками и звуками природы.

## ✨ Возможности и особенности

- **🎙️ Студийные русскоязычные медитации (UCLA MARC):**
  - *Осознанное дыхание* (7:50) — обучение базовому фокусу и ясности.
  - *Сканирование тела* (4:00) — глубокое снятие мышечных и ментальных зажимов.
  - *Дыхание, звуки и тело* (10:20) — расширенная практика присутствия.
  - *Метта / Доброжелательность* (13:00) — развитие сострадания и снижения тревоги.
  - *Полная сессия* (20:45) — глубокое погружение для опытных практиков.
- **🫁 Осознанные практики дыхания:**
  - *Квадрат 4-4-4-4 (Box Breathing)* — быстрый сброс кортизола и концентрация.
  - *Релакс 4-7-8 (Эндрю Вейл)* — активация парасимпатической системы перед сном.
  - *Когерентное дыхание (5.5с / 5.5с)* — гармонизация вариабельности сердечного ритма (HRV).
  - Плавная синхронизация визуального светового ореола с точными миллисекундными фазами.
- **🌲 Стереофонические звуковые ландшафты:**
  - Огонь и потрескивание костра 🔥
  - Летняя звёздная ночь и сверчки 🦗
  - Освежающий дождь 🌧️
  - Океанский прибой 🌊
  - Горный лесной ветер 🍃
  - Тибетская поющая чаша по клавише `[B]` 🔔
- **🎛️ Независимый аудио-микшер:**
  - Раздельная настройка громкости голоса диктора и фоновых звуков природы.
  - Автоматическое приглушение фона во время речи диктора (Smart Auto-Ducking).
- **🌌 Интерактивный живой фон (Zen Flow-Field):**
  - Шелковистая органическая 2D-физика движения частиц (Harmonic Wave Drift).
  - Мягкая вихревая реакция на движение мыши (Viscous Damping) и водяные круги (Ripples).
  - Адаптивные палитры под выбранный звук природы.
- **💎 Дизайн-система в стиле `lofi-night-sky`:**
  - Стекломорфизм `glass-pill` (`backdrop-filter: blur(20px)`).
  - Шрифты: *Jost* (заголовки), *Manrope* (текст), *JetBrains Mono* (метки).
  - Стартовый экран *Enter the Zen* с созвездием и переключателем языка `[ EN | RU ]`.
  - Парящий баннер аффирмаций в небе.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| <kbd>Space</kbd> | Старт / Пауза текущей практики |
| <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd> | Переключение режимов (Медитация / Дыхание / Атмосфера) |
| <kbd>B</kbd> | Удар в тибетскую поющую чашу |
| <kbd>M</kbd> | Вкл / Выкл звук (Mute) |
| <kbd>F</kbd> | Полноэкранный режим |
| <kbd>Esc</kbd> | Закрыть любое открытое окно |

## 🚀 Запуск и разработка

```bash
# Клонировать репозиторий
git clone https://github.com/ilyachu/zenspace.git
cd zenspace

# Установить зависимости
npm install

# Запустить локальный сервер
npm run dev

# Собрать продакшн-билд
npm run build
```
