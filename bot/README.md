# 🤖 ZenSpace Telegram Companion Bot

Telegram-бот для удержания пользователей (Retention), ежедневных аффирмаций и мягких вечерних напоминаний с прямым запуском **ZenSpace Mini App**.

---

## ✨ Возможности

1. **Запуск WebApp в Telegram:**
   - Интерактивная кнопка «🧘 Войти в ZenSpace».
   - Автоматическая установка кнопки Меню (MenuButtonWebApp) в левом нижнем углу чата Telegram.
2. **Утренние аффирмации (09:00 МСК):**
   - Ежедневная отправка мудрой мысли из ночного неба ZenSpace для настройки на день.
3. **Вечерние напоминания о дыхании (22:00 МСК):**
   - Мягкий сигнал замедлиться перед сном с практикой 4-7-8 или звуками ночи.
4. **Быстрые команды:**
   - `/start` — Приветствие и запуск.
   - `/zen` — Случайная мысль дня.
   - `/breathe` — Квадратное дыхание (Box Breathing 4-4-4-4).
   - `/frequencies` — Гид по частотам Сольфеджио (432 Гц, 528 Гц) и бинауральным ритмам.
   - `/remind` — Настройка персонального времени уведомлений.
5. **База данных:**
   - SQLite (`zenspace_bot.db`) без сложных внешних зависимостей.

---

## 🚀 Быстрый запуск

### 1. Создание бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`, укажите имя и username (например, `zenspace_mind_bot`).
3. Скопируйте полученный **API Token**.
4. *(Опционально)* Настройте Mini App кнопку:
   - В диалоге с @BotFather отправьте `/setmenubutton`.
   - Выберите созданного бота.
   - Введите URL: `https://zenspace.vercel.app`
   - Введите название кнопки: `ZenSpace`

### 2. Установка зависимостей и запуск

```bash
cd bot

# Установить зависимости
pip install -r requirements.txt

# Скопировать и настроить .env
cp .env.example .env
# Отредактируйте .env и вставьте ваш токен

# Запустить бота
python3 main.py
```

Или в одну строку:
```bash
BOT_TOKEN="ВАШ_ТОКЕН" WEBAPP_URL="https://zenspace.vercel.app" python3 bot/main.py
```
